# release-notes/android

Play 릴리스의 "이번 버전의 새로운 기능"이다. `<언어 코드>.txt` 파일 하나가 한 언어이고,
`android-play-upload.sh`가 있는 대로 실어 보낸다(디렉터리가 없으면 노트 없이 올린다).

- **언어당 500자**가 상한이다. 넘으면 Play가 그 릴리스를 거절한다.
- **릴리스마다 갱신한다.** 갱신을 잊으면 지난 노트가 그대로 나가므로, 스크립트가 보낼 내용을
  실행할 때 출력한다. 언어를 늘리려면 파일을 하나 더 두면 된다(`de-DE.txt` 등).
- 서비스 도메인·주소는 적지 않는다 — 배포마다 달라지는 값이라 노트가 먼저 낡는다.
