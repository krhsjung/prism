# web

Prism 웹 클라이언트 — React + Vite + TypeScript.

## 실행

```bash
npm install
npm run dev       # 개발 서버 (HMR)
npm run build     # 타입체크 + 프로덕션 빌드
npm run preview   # 빌드 산출물 미리보기
```
